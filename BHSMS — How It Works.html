Overview
One system for three barangay health stations
BHSMS records residents, vital signs, pregnancies and vaccines. It keeps working offline and syncs to the cloud when the signal comes back.

  3. The system builds a match key and warns if it already exists.

How the code works · Access control
Three locks on patient data
In the app
ModuleGuard
Each page asks hasModule(). Roles give defaults; an admin can add or remove modules per user.
In the database
Row-Level Security
Supabase policies on every table. Only admin, doctor, nurse and BHW can read residents.

Who did what, on which table and record, for RA 10173, the Data Privacy Act.
